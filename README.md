# 📺 LGS IPTV

**O futuro do streaming na sua TV, celular e PC.**

Uma interface premium, rápida e imersiva construída do zero para provedores de IPTV.

## 🚀 Sobre o Projeto

O **LGS IPTV** não é apenas mais um player na web. Ele foi arquitetado para ser um **Super App** multiplataforma. Seja no navegador do seu computador, no celular ou empacotado dentro de uma Smart TV (Android TV, Tizen, WebOS), a experiência é idêntica e profissional.

## ✨ Funcionalidades

- 📡 **Conexões Múltiplas:** Suporte nativo a Xtream Codes API e arquivos M3U/M3U8.
- 🎮 **D-Pad Navigation:** Navegação espacial para controle remoto (Smart TV).
- 🎬 **Player de Cinema:** Interface estilo Netflix com auto-hide, pular 10s e barra interativa.
- ⏱️ **Continuar Assistindo:** Salva o progresso automaticamente.
- 🔐 **Sistema de MAC Address:** Gera um ID único para o dispositivo.
- 🍿 **Hub Central:** Separação entre Ao Vivo, Filmes e Séries.
- 🎨 **Design Premium:** Glassmorphism e animações suaves.

## 🛠️ Tecnologias

- HTML5, CSS3, JavaScript (Vanilla)
- HLS.js (Para streams .m3u8)
- LocalStorage (Banco de dados local)
